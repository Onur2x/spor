HIZLI KAS GELİŞİMİ

2 Gün Çalışma + 1 Gün Dinlenme Routine

Önemli Kurallar

  • Progressive Overload: Her hafta ağırlık veya tekrarı kademeli artırın.
  • Kardiyo: Ağırlık antrenmanı bittikten sonra 20-25 dk orta tempo.
  • Form & Hız: Ağırlığı kaldırırken direnç gösterin, indirirken 2-3 sn yavaş indirin.

GÜN 1: PUSH (Göğüs, Omuz, Arka Kol)

  • 1. Barbell Bench Press
    3 Set x 10-12 Tekrar | Dinlenme: 90sn
  • 2. Dumbbell Incline Press
    3 Set x 10-12 Tekrar | Dinlenme: 90sn
  • 3. Pec Deck / Butterfly Makinesi
    3 Set x 12-15 Tekrar | Dinlenme: 60sn
  • 4. Dumbbell Seated Shoulder Press
    3 Set x 10-12 Tekrar | Dinlenme: 90sn
  • 5. Lateral Raise Makinesi
    3 Set x 15 Tekrar | Dinlenme: 60sn
  • 6. Cable Face Pull
    3 Set x 15 Tekrar | Dinlenme: 60sn
  • 7. Triceps Pushdown
    3 Set x 12-15 Tekrar | Dinlenme: 60sn
  • 8. Dumbbell Overhead Triceps Extension
    3 Set x 12 Tekrar | Dinlenme: 60sn

GÜN 2: PULL & LEGS (Sırt, Bacak, Ön Kol, Karın)

  • 1. Lat Pulldown Makinesi
    3 Set x 10-12 Tekrar | Dinlenme: 90sn
  • 2. Seated Cable Row
    3 Set x 10-12 Tekrar | Dinlenme: 90sn
  • 3. Dumbbell One Arm Row
    3 Set x 10-12 Tekrar | Dinlenme: 60sn
  • 4. Leg Press Makinesi
    3 Set x 10-12 Tekrar | Dinlenme: 90sn
  • 5. Leg Extension Makinesi
    3 Set x 12 Tekrar | Dinlenme: 60sn
  • 6. Leg Curl Makinesi
    3 Set x 12 Tekrar | Dinlenme: 60sn
  • 7. Barbell Biceps Curl
    3 Set x 10-12 Tekrar | Dinlenme: 60sn
  • 8. Dumbbell Hammer Curl
    3 Set x 10-12 Tekrar | Dinlenme: 60sn
  • 9. Cable Crunch (Karın)
    3 Set x 15-20 Tekrar | Dinlenme: 45sn
  • 10. Plank
    3 Set x Maksimum Süre | Dinlenme: 45sn
